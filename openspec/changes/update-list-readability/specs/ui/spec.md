# Spec Delta

## ADDED Requirements

### Requirement: ポップオーバーの文字の読みやすさ

ポップオーバーに出す文字（一覧、取得の状態、操作の失敗、案内の文、件数、ボタンの文）は、11pt より小さくしてはならない（MUST NOT）。スレッドの件名とアカウントの見出しのユーザー名は 13pt で出さなければならない（SHALL）。アカウントの見出しのユーザー名とリポジトリの見出し（`owner/name`）は見出しとして、太字にし、薄い色にせず標準の文字色で出さなければならない（SHALL）。薄い色（システムの副次的な文字色）は、補足の情報（スレッドの行の番号・理由・更新日時、ホスト名とホスト種別、「Updated」などの取得の状態、折りたたんだときの件数）にだけ使わなければならない（SHALL）。文字の色はシステムの文字色を使い、独自の色や透明度を掛けた色にしてはならない（MUST NOT）。システムの「コントラストを上げる」と「透明度を下げる」をオンにしたときは、ポップオーバーの文字もそれに従って濃くならなければならない（SHALL）。文字を大きくしても、ポップオーバーの幅（380pt）は変えてはならず（MUST NOT）、横にスクロールさせてはならない（MUST NOT）。アカウントの見出しのホスト名は 1 行に収め、収まらないときは省略しなければならない（SHALL）。スレッドの件名は 2 行まで出し、それより長いときは省略しなければならない（SHALL）。メニューバーのアイコンと件数、設定ウィンドウの文字には、この Requirement は適用しない。

#### Scenario: スレッドの行

- **GIVEN** `github.com/alice` の `octo/app` に、Pull request `#42`、理由 `review_requested` のスレッドがある
- **WHEN** ユーザーがポップオーバーを開く
- **THEN** 件名は 13pt で標準の文字色で出る
- **AND** `#42`、理由、更新日時の行は 11pt で薄い色で出る
- **AND** `octo/app` の見出しは 11pt の太字で、標準の文字色で出る

#### Scenario: アカウントの見出し

- **GIVEN** `acme.ghe.com/dave`（使える、アクティブ）がある
- **WHEN** ユーザーがポップオーバーを開く
- **THEN** `dave` は 13pt の太字で、標準の文字色で出る
- **AND** アクティブの印と「acme.ghe.com — GHE Cloud」は 11pt で出る

#### Scenario: 取得の状態と操作の失敗

- **GIVEN** `github.com/alice` の取得ができていて、直前の既読の操作が失敗している
- **WHEN** ユーザーがポップオーバーを開く
- **THEN** 「Updated」の行と操作の失敗の文は 11pt 以上で出る

#### Scenario: 長いホスト名と件名

- **GIVEN** ホスト名が 40 文字ある GHES のアカウントに、件名が 200 文字のスレッドがある
- **WHEN** ユーザーがポップオーバーを開く
- **THEN** ポップオーバーの幅は 380pt のままで、横にスクロールしない
- **AND** 見出しのホスト名は 1 行に省略して出て、件名は 2 行まで出て省略される

#### Scenario: コントラストを上げる

- **GIVEN** システムの「コントラストを上げる」がオン
- **WHEN** ユーザーがポップオーバーを開く
- **THEN** 薄い色の文字も含めて、オフのときより背景とのコントラストが高く出る
