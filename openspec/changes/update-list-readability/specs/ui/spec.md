# Spec Delta

## ADDED Requirements

### Requirement: ポップオーバーの文字の読みやすさ

ポップオーバーに出す文字（一覧、取得の状態、操作の失敗、案内の文、件数、ボタンの文）は、11pt より小さくしてはならない（MUST NOT）。スレッドの件名とアカウントの見出しのユーザー名は 13pt で出さなければならない（SHALL）。アカウントの見出しのユーザー名とリポジトリの見出し（`owner/name`）は見出しとして、太字にし、薄い色にせず標準の文字色で出さなければならない（SHALL）。

薄い色（システムの副次的な文字色）は、次の補足の情報にだけ使わなければならない（SHALL）: スレッドの行の番号・理由・更新日時、ホスト名とホスト種別、取得中・取得できた時刻などの取得の状態（「Checking gh…」「Loading notifications…」「Updated …」）、未読が無いことの表示、折りたたんだときの件数。それ以外の文（トークンを取れないときやスコープ不足・認証エラーの案内、操作の失敗、一覧を打ち切ったことの知らせ、すべて既読の確認の文）は標準の文字色で出さなければならない（SHALL）。

文字の色はシステムの文字色だけを使い、独自の色や透明度を掛けた色にしてはならない（MUST NOT）。システムの「コントラストを上げる」をオンにしたときは、薄い色の文字も含めて背景とのコントラストが上がらなければならない（SHALL）。システムの「透明度を下げる」をオンにしたときは、ポップオーバーの背景がシステムの設定に従って不透明になり、後ろのウィンドウの色が文字の背景に透けてはならない（SHALL）。

アイコン（種類のアイコン、見出しの山形、トークンの状態、参加のみの印）は、並ぶ文字と同じ大きさの書体で描かなければならない（SHALL）。大きさの下限と色の決まりはアイコンにも当てはめる。

文字を大きくしても、ポップオーバーの幅（380pt）は変えてはならず（MUST NOT）、横にスクロールさせてはならない（MUST NOT）。アカウントの見出しは 1 行に収めなければならない（SHALL）。幅が足りないときは、まずホスト名とホスト種別を省略し、それでも足りなければユーザー名の末尾を省略しなければならない（SHALL）。active の印、折りたたんだときの件数、すべて既読の確認の文は省略してはならない（MUST NOT）。リポジトリの見出しは 1 行に収め、収まらないときは中央を省略しなければならない（SHALL）。省略したホスト名・リポジトリ名は、その文字にマウスを載せたツールチップで全体を読めなければならない（SHALL）。スレッドの件名は 2 行まで出し、それより長いときは省略しなければならない（SHALL）。

メニューバーのアイコンと件数、設定ウィンドウの文字には、この Requirement は適用しない。

#### Scenario: スレッドの行

- **GIVEN** `github.com/alice` の `octo/app` に、Pull request `#42`、理由 `review_requested` のスレッドがある
- **WHEN** ユーザーがポップオーバーを開く
- **THEN** 件名は 13pt で標準の文字色で出る
- **AND** `#42`、理由、更新日時の行は 11pt で薄い色で出る
- **AND** `octo/app` の見出しは 11pt の太字で、標準の文字色で出る

#### Scenario: アカウントの見出し

- **GIVEN** `acme.ghe.com/dave`（使える、アクティブ）がある
- **WHEN** ユーザーがポップオーバーを開く
- **THEN** `dave` は 13pt の太字で、標準の文字色で出る
- **AND** アクティブの印と「acme.ghe.com — GHE Cloud」は 11pt で出る

#### Scenario: 取得の状態と操作の失敗

- **GIVEN** `github.com/alice` の取得ができていて、直前の既読の操作が失敗している
- **WHEN** ユーザーがポップオーバーを開く
- **THEN** 「Updated」の行と操作の失敗の文は 11pt 以上で出る
- **AND** 操作の失敗の文とトークンを取れないときの案内は標準の文字色で出る

#### Scenario: 長いホスト名と件名

- **GIVEN** ホスト名が 40 文字以上ある GHES のアカウントに、件名が 200 文字のスレッドがある
- **WHEN** ユーザーがポップオーバーを開く
- **THEN** ポップオーバーの幅は 380pt のままで、横にスクロールしない
- **AND** 見出しのホスト名は 1 行に省略して出て、件名は 2 行まで出て省略される
- **AND** ホスト名にマウスを載せると、ツールチップで全体が読める

#### Scenario: 長いユーザー名

- **GIVEN** 39 文字のユーザー名の active のアカウントで、すべて既読のボタンを 1 回押して確認の文が出ている
- **WHEN** ユーザーがポップオーバーを見る
- **THEN** 見出しは 1 行のままで、ホスト名が先に省略され、ユーザー名は収まらない分だけ末尾が省略される
- **AND** active の印と確認の文は省略されない

#### Scenario: 長いリポジトリ名

- **GIVEN** 長い `owner/name` のリポジトリの未読がある
- **WHEN** ユーザーがポップオーバーを開く
- **THEN** リポジトリの見出しは 1 行で、中央が省略される
- **AND** 見出しにマウスを載せると、ツールチップで `owner/name` の全体が読める

#### Scenario: コントラストを上げる

- **GIVEN** システムの「コントラストを上げる」がオン
- **WHEN** ユーザーがポップオーバーを開く
- **THEN** 薄い色の文字も含めて、オフのときより背景とのコントラストが高く出る

#### Scenario: 透明度を下げる

- **GIVEN** システムの「透明度を下げる」がオン
- **WHEN** ユーザーがポップオーバーを開く
- **THEN** ポップオーバーの背景は不透明になり、後ろのウィンドウの色が文字の背景に透けない
