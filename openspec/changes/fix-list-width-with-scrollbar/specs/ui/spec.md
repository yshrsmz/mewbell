# Spec Delta

## ADDED Requirements

### Requirement: スクロールバーによる一覧の幅

ポップオーバーの一覧の中身の幅は、一覧のスクロールバーが出ているかどうかで変えてはならない（MUST NOT）。スクロールバーが中身に重ならずに幅を使う表示（macOS の「スクロールバーを表示」が「常に」のとき、または「マウスまたはトラックパッドに応じて自動的に」でマウスをつないでいるとき）では、スクロールバーが出ていないとき（一覧がポップオーバーに収まっているとき、開閉のアニメーションの間にスクロールバーを隠しているとき）にも、一覧の中身の右にスクロールバーと同じ幅の空きを残さなければならない（SHALL）。スクロールバーが中身に重なる表示では、空きを残してはならない（MUST NOT）。一覧を表示している間にシステム設定でスクロールバーの表示を切り替えたときは、切り替えた後の表示に合わせなければならない（SHALL）。この空きのために、ポップオーバーの幅（380pt）を変えてはならず（MUST NOT）、一覧を横にスクロールさせてはならない（MUST NOT）。

#### Scenario: Done で一覧が収まってもボタンが動かない

- **GIVEN** スクロールバーが常に出る表示で、`github.com/alice` の一覧がポップオーバーに収まらず、スクロールバーが出ている
- **AND** ユーザーがスレッドの行にマウスを載せている
- **WHEN** ユーザーが「Done にする」のボタンを押し、行が消えて一覧がポップオーバーに収まり、スクロールバーが消える
- **THEN** 次のスレッドの行の「既読にする」と「Done にする」のボタンは、押したボタンと同じ横の位置に出る
- **AND** 一覧の中身の右には、スクロールバーと同じ幅の空きが残る

#### Scenario: 一覧が伸びてスクロールバーが出てもボタンが動かない

- **GIVEN** スクロールバーが常に出る表示で、一覧がポップオーバーに収まっていて、スクロールバーが出ていない
- **WHEN** 新着が届くかリポジトリの見出しを開いて、一覧がポップオーバーに収まらなくなり、スクロールバーが出る
- **THEN** アカウントの見出しのすべて既読のボタンとスレッドの行のボタンの横の位置は変わらない
- **AND** スクロールバーは、それまで空きを残していた場所に出る

#### Scenario: 開閉のアニメーションの間も幅が変わらない

- **GIVEN** スクロールバーが常に出る表示で、一覧がポップオーバーに収まらず、スクロールバーが出ている
- **WHEN** ユーザーがリポジトリの見出しで折りたたみ、アニメーションの間スクロールバーが隠れる
- **THEN** アニメーションの間もその後も、一覧の中身の幅は変わらない

#### Scenario: スクロールバーが重なる表示では空きを残さない

- **GIVEN** スクロールバーが中身に重なる表示（トラックパッドだけで「マウスまたはトラックパッドに応じて自動的に」）で、一覧がポップオーバーに収まっている
- **WHEN** ユーザーがポップオーバーを開く
- **THEN** 一覧の中身の右に空きは残らず、中身はポップオーバーの余白の内側の幅いっぱいに出る

#### Scenario: 表示中にスクロールバーの設定を切り替える

- **GIVEN** スクロールバーが中身に重なる表示で、一覧がポップオーバーに収まった状態でポップオーバーを開いている
- **WHEN** ユーザーがシステム設定で「スクロールバーを表示」を「常に」に切り替える
- **THEN** 一覧の中身の右に、スクロールバーと同じ幅の空きが残る
- **AND** ポップオーバーの幅は 380pt のままで、横にスクロールしない
