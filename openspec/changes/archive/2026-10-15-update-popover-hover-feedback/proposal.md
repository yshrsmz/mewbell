# Proposal

## Why

ポップオーバーで押せる要素のうち、マウスを載せたときに見た目が変わるのは、見出しの歯車と再読み込みのボタンだけである。スレッドの行の既読・Done のボタン、アカウントの見出しの Web の通知一覧のボタンとすべて既読のボタン、コマンドのコピーのボタン、スレッドの行そのもの、アカウントとリポジトリの開閉の見出しは、マウスを載せても見た目が変わらない。どこが押せるのか、押すとどの範囲が反応するのかが、押してみるまで分からない。同じポップオーバーの中で、歯車と再読み込みだけが反応するのも揃っていない。

マイルストーン: M4（設定と操作）で足した操作の見た目の手直し。新しい操作は足さない。SETUP.md のマイルストーンの表には行を足さない。

## What Changes

- アイコンだけのボタン（スレッドの行の既読・Done、アカウントの見出しの Web の通知一覧・すべて既読、コマンドのコピー）にマウスを載せると、歯車と再読み込みと同じ、アイコンの後ろの角丸の薄い塗りが出る。押している間は塗りが濃くなる。押せないときは塗りを出さない
- すべて既読のボタンの確認の表示（`Mark N as read?` など）にも、同じ塗りを付ける。文字はシステムのアクセントカラーのまま
- スレッドの行、アカウントの見出しの開閉、リポジトリの見出しの開閉にマウスを載せると、押せる範囲に角丸の薄い塗りが出る。押している間は塗りが濃くなる
- アカウントとリポジトリの見出しの開閉の押せる範囲を、見出しの中身の幅から、見出しの行の空いている幅いっぱいに広げる（アカウントの見出しは、Web の通知一覧とすべて既読のボタンの手前まで。ボタンとは重ねない）。塗りもその範囲に出す。スレッドの行の押せる範囲は変えない
- Quit、Open Settings…、Open cli.github.com などのシステム標準の押しボタンは変えない（macOS の標準の見た目のまま）
- 設定ウィンドウは変えない

## Capabilities

### New Capabilities

なし。

### Modified Capabilities

- `ui`: ポップオーバーの押せる要素が、マウスを載せている間と押している間に見た目の反応を返すことを足す（新しい Requirement）。既存の「ポップオーバーの文字の読みやすさ」が許す「ボタンの囲みの薄い塗り」の範囲で行い、文字の色の決まりは変えない

## Impact

- コード: `Mewbell/UI/ReloadButton.swift`（今の `PressableIconButtonStyle` を、行と見出しにも使えるボタンのスタイルにして別のファイルへ移す）、`ThreadRow.swift`（行、既読・Done、すべて既読のボタン）、`OpenWebNotificationsButton.swift`、`CommandRow.swift`、`DisclosureButton.swift`、`RepositoryGroupView.swift`、`OpenSettingsButton.swift`（スタイルの名前の変更に合わせる）
- トークン: 触れない
- gh サブプロセス: 触れない
- ネットワーク: 触れない
- URL を開く処理: 触れない（開くボタンの見た目だけを変え、開く経路と検査は変えない）
- 永続化: しない。マウスを載せている状態は View の中にだけ持つ
