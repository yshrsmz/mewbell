# Proposal

## Why

ポップオーバーのアカウントの見出しで、ユーザー名だけが `active` の印とホスト名より下に沈んで見える。

アカウントの見出しの中身（トークンの状態のアイコン、ユーザー名、アクティブの印、ホスト名、参加のみの印）は、`AccountHeadingView` の `title` の `HStack` に既定の中央揃えで並んでいる。ユーザー名は `.headline`（13pt の太字）、アクティブの印とホスト名は `.subheadline`（11pt）で、大きさの違う文字を中央で揃えると、ベースラインが合わない。手元の倍率 2 の画面で撮って測ると、ユーザー名のベースラインはアクティブの印とホスト名より 3px（1.5pt）下にあった。

| 要素 | ベースライン（px） | インクの縦の中心（px） |
|---|---|---|
| ユーザー名（13pt） | 164 | 154.0 |
| アクティブの印（11pt） | 161 | 153.0 |
| ホスト名（11pt） | 161 | 153.0 |
| 山形 | – | 154.5 |
| トークンの状態のアイコン | – | 153.5 |

一方、山形とトークンの状態のアイコンは、文字の中心から 0.5pt 以内に揃っていて、ずれは目立たない。リポジトリの見出しは、山形・リポジトリ名・件数がどれも 11pt なので、ベースラインのずれは無い。

この change は、M4（設定と操作）の UI の不具合の修正にあたる（M5 の公開後）。fix-thread-icon-column で Non-Goals に分けた「見出しのベースラインの揃え」を扱う。

## What Changes

- 見出しの文字（アカウントの見出しのユーザー名・アクティブの印・ホスト名・参加のみの印と、折りたたんだときの件数。リポジトリの見出しのリポジトリ名と件数）を、同じベースラインに揃える
- 見出しの山形とアカウントの見出しのトークンの状態のアイコンは、今のまま縦の中央に置く。取得中の印（`ProgressView`）は文字のベースラインを持たないので、ベースラインの揃えには入れない
- そのために、開閉のボタン（`DisclosureButton`）に、山形の次に置くアイコンを受け取る引数を足す。アカウントの見出しはトークンの状態のアイコンをここに渡し、見出しの中身（`label`）は文字だけにする。リポジトリの見出しはアイコンを渡さない
- ui に Requirement「見出しの文字のベースライン」を足す（ADDED）

## Capabilities

### New Capabilities

（なし）

### Modified Capabilities

- `ui`: Requirement「見出しの文字のベースライン」を足す（ADDED）。表示する項目・書体・色・操作・読み上げは変えない。「見出しの押せる範囲の高さ」の、山形・トークンの状態・ユーザー名を塗りの縦の中央に置く決まりは保つ

## Impact

- 変わるコード: `Mewbell/UI/DisclosureButton.swift`（アイコンの引数と、文字と件数をベースラインで揃える並び）、`Mewbell/UI/AccountHeadingView.swift`（トークンの状態のアイコンを `title` から開閉のボタンの引数に移す）
- 見た目: アカウントの見出しで、アクティブの印・ホスト名・参加のみの印・件数が、ユーザー名のベースラインに揃う。見出しの高さ（24pt）、アイコンの列、字下げ、省略のしかたは変わらない。リポジトリの見出しの見た目は変わらない見込み
- トークン: 扱わない。何も永続化しない
- gh サブプロセス: 触れない
- ネットワーク: 触れない
- URL を開く処理: 触れない
- 外部依存: 追加しない
