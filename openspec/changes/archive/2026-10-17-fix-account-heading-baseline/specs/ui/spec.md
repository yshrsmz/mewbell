# Spec Delta

## ADDED Requirements

### Requirement: 見出しの文字のベースライン

ポップオーバーの一覧のアカウントの見出しとリポジトリの見出しでは、見出しの文字（ユーザー名、アクティブの印、ホスト名、リポジトリ名、折りたたんだときの件数）を、文字の大きさが違っても同じベースラインに揃えなければならない（SHALL）。参加のみの印は、見出しの文字の中に置いた記号として、同じベースラインに置かなければならない（SHALL）。見出しの山形とアカウントの見出しのトークンの状態のアイコン（取得中の印を含む）は、ベースラインではなく見出しの縦の中央に置かなければならない（SHALL）。この決まりで、見出しの高さ、アイコンの列、字下げ、省略のしかたを変えてはならない（MUST NOT）。

#### Scenario: アカウントの見出しの文字

- **GIVEN** `github.com/alice`（使える、アクティブ）の取得ができていて、参加しているスレッドだけを出す設定になっている
- **WHEN** ユーザーがポップオーバーを開く
- **THEN** `alice`（13pt）、アクティブの印、`github.com`（11pt）、参加のみの印は、同じベースラインに並ぶ
- **AND** 山形とトークンの状態のアイコンは、見出しの縦の中央に出る

#### Scenario: 折りたたんだアカウントの見出しの件数

- **GIVEN** `github.com/alice`（アクティブ）に未読が 3 件ある
- **WHEN** ユーザーが `alice` の見出しを折りたたむ
- **THEN** 件数の `3` は、`alice`、アクティブの印、`github.com` と同じベースラインに並ぶ

#### Scenario: トークンを取得している間

- **GIVEN** `github.com/alice` のトークンを取得している
- **WHEN** ユーザーがポップオーバーを開く
- **THEN** 取得中の印は、見出しの縦の中央に出る
- **AND** `alice` とアクティブの印と `github.com` は、同じベースラインに並ぶ

#### Scenario: リポジトリの見出し

- **GIVEN** `github.com/alice` の `octo/app` に未読が 2 件ある
- **WHEN** ユーザーが `octo/app` の見出しを折りたたむ
- **THEN** `octo/app` と件数の `2` は、同じベースラインに並ぶ
- **AND** 山形は、見出しの縦の中央に出る
