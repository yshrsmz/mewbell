# Spec Delta

## MODIFIED Requirements

### Requirement: 再読み込みボタン

ポップオーバーには、gh の検出とアカウントの読み取りをやり直す「再読み込み」ボタンがなければならない（SHALL）。「再読み込み」を押すと、通知の取得が「スコープ不足」か「認証エラー」で止まっているアカウントの取得も再開しなければならない（SHALL）。取得を続けているアカウントについては、次の取得を `If-Modified-Since` を付けない取得にしなければならない（SHALL。polling「条件付きリクエスト」）。このとき、取得を間隔より早めてはならない（MUST NOT）。読み直している間はボタンを押せないようにしなければならない（SHALL）。

#### Scenario: gh をインストールした後に再読み込みする

- **GIVEN** 全体の状態が「gh が見つからない」で、ユーザーがその後 `brew install gh` と `gh auth login` を済ませた
- **WHEN** ユーザーが「再読み込み」を押す
- **THEN** 確認中の表示を経て、アカウントの区画が表示される

#### Scenario: スコープ不足からの再開

- **GIVEN** `github.com/alice` が「スコープ不足」で、ユーザーがその後スコープを足した
- **WHEN** ユーザーが「再読み込み」を押す
- **THEN** `alice` の区画は最初の取得中の表示を経て、通知の一覧になる

#### Scenario: 一覧のずれを再読み込みで直す

- **GIVEN** `alice` の一覧に、Web で既読にしたスレッドがまだ表示されている
- **WHEN** ユーザーが「再読み込み」を押し、次の取得の時刻になる
- **THEN** その取得は `If-Modified-Since` を付けずに送られ、既読にしたスレッドは一覧から消える
