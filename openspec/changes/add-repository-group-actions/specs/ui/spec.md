## ADDED Requirements

### Requirement: リポジトリの見出しの操作

ポップオーバーの一覧のリポジトリの見出しには、ブラウザで開かずにそのグループのスレッドをまとめて既読にする「既読にする」と、まとめて Done にする「Done にする」の操作がなければならない（SHALL）。2 つの操作は、見出しにマウスを載せている間だけ見出しの右端にボタンとして表示し（SHALL）、同じ 2 つを見出しのコンテキストメニュー（右クリック）と、VoiceOver の操作（アクセシビリティのアクション）にも出さなければならない（SHALL）。グループを折りたたんでいても、同じように出さなければならない（SHALL）。ボタンにはツールチップとアクセシビリティのラベルを付け、どのリポジトリへの操作かが分かるようにしなければならない（SHALL）。どの操作でもブラウザを開いてはならず（MUST NOT）、ボタンを押したときに見出しの折りたたみが同時に起きてはならない（MUST NOT）。ボタンを出している間も、見出しの高さとリポジトリ名の位置を変えてはならない（MUST NOT）。ボタンに重なるリポジトリ名と件数は、ボタンの下に透けないように隠してよい（MAY）。

「既読にする」は、押したらすぐに polling「リポジトリのグループの既読化と Done」に従って既読にしなければならない（SHALL）。

「Done にする」は、取り消せず複数のスレッドに効くので、1 回目に押したときはリクエストを送らずに、ボタンを件数を含む確認の表示（`Mark N as done?`。N はそのグループのスレッドの件数）に変えなければならない（SHALL）。コンテキストメニューと VoiceOver の操作で「Done にする」を選んだときも、すぐには行わずに、見出しのボタンを同じ確認の表示にしなければならない（SHALL）。確認の表示は、マウスを見出しから外しても出し続けなければならない（SHALL）。確認の表示のまま 5 秒以内にそのボタンを押したときだけ、polling「リポジトリのグループの既読化と Done」に従って Done にしなければならない（SHALL）。5 秒たったとき、ポップオーバーを閉じたとき、そのグループの件数か最新のスレッドが変わったとき、グループが一覧から消えたときは、リクエストを送らずに元の表示に戻さなければならない（SHALL）。確認の表示は操作したグループの見出しだけに出し、ほかのグループやアカウントの見出しに影響してはならない（MUST NOT）。確認の文は、アカウントのすべて既読の確認と同じく、アクセントカラーで出さなければならない（SHALL）。

#### Scenario: ホバーで操作が出る

- **GIVEN** `github.com/alice` の一覧に `octo/app` のスレッドが 2 件ある
- **WHEN** ユーザーが `octo/app` の見出しにマウスを載せる
- **THEN** 見出しの右端に「既読にする」と「Done にする」のボタンが出る
- **AND** マウスを見出しから外すとボタンは消える

#### Scenario: グループを既読にする

- **GIVEN** `octo/app` の見出しにマウスを載せている
- **WHEN** ユーザーが「既読にする」のボタンを押す
- **THEN** ブラウザは開かず、`octo/app` のグループが一覧からすぐに消え、グループのスレッドごとに `PATCH /notifications/threads/{id}` が送られる
- **AND** `octo/app` の見出しは折りたたまれない

#### Scenario: 2 回押してグループを Done にする

- **GIVEN** `octo/app` の見出しにマウスを載せていて、グループに 2 件ある
- **WHEN** ユーザーが「Done にする」のボタンを押す
- **THEN** ボタンは `Mark 2 as done?` の表示に変わり、リクエストは送られない
- **AND** 5 秒以内にもう一度押すと、`octo/app` のグループが一覧から消え、グループのスレッドごとに `DELETE /notifications/threads/{id}` が送られる

#### Scenario: コンテキストメニューで Done を選ぶ

- **GIVEN** `github.com/alice` の一覧に `octo/app` のスレッドが 3 件ある
- **WHEN** ユーザーが `octo/app` の見出しを右クリックし、「Done にする」を選ぶ
- **THEN** リクエストは送られず、見出しのボタンが `Mark 3 as done?` の表示になる
- **AND** 5 秒以内にそのボタンを押すと、グループのスレッドが Done になる

#### Scenario: コンテキストメニューで既読にする

- **GIVEN** `github.com/alice` の一覧に `octo/app` のスレッドが 2 件ある
- **WHEN** ユーザーが `octo/app` の見出しを右クリックし、「既読にする」を選ぶ
- **THEN** 確認の表示にはならず、`octo/app` のグループが一覧からすぐに消える

#### Scenario: Done の確認のまま時間が過ぎる

- **GIVEN** ユーザーが `octo/app` の「Done にする」を 1 回押し、確認の表示になっている
- **WHEN** 5 秒がたつ
- **THEN** ボタンは元の表示に戻り、リクエストは送られない

#### Scenario: 確認の途中で新着が届く

- **GIVEN** ユーザーが `octo/app` の「Done にする」を 1 回押し、`Mark 2 as done?` の表示になっている
- **WHEN** 5 秒以内の取得で `octo/app` の新しいスレッドが届き、グループが 3 件になる
- **THEN** ボタンは元の表示に戻り、次に押しても確認の表示になるだけでリクエストは送られない

#### Scenario: 折りたたんだグループを Done にする

- **GIVEN** `octo/app` のグループを折りたたんでいて、見出しに `2` と出ている
- **WHEN** ユーザーが見出しの「Done にする」を 2 回押す
- **THEN** 隠れていた 2 件のスレッドが Done になり、`octo/app` の見出しが一覧から消える

#### Scenario: ほかのグループに影響しない

- **GIVEN** `github.com/alice` の一覧に `octo/app` と `octo/lib` のグループがある
- **WHEN** ユーザーが `octo/app` の「Done にする」を 1 回押す
- **THEN** `octo/app` の見出しだけが確認の表示になり、`octo/lib` の見出しとアカウントのすべて既読のボタンは変わらない

## MODIFIED Requirements

### Requirement: ポップオーバーの押せる要素のホバーの反応

ポップオーバーの次の要素は、マウスを載せている間、押せる範囲に薄い塗りを出して、押せることと押したときに反応する範囲が分かるようにしなければならない（SHALL）。押している間は、マウスを載せているときより濃い塗りにしなければならない（SHALL）。

- アイコンだけのボタン: 見出しの歯車と再読み込み、スレッドの行の「既読にする」と「Done にする」、リポジトリの見出しの「既読にする」と「Done にする」（確認の表示のときも含む）、アカウントの見出しの Web の通知一覧のボタンとすべて既読のボタン（確認の表示のときも含む）、コマンドの行のコピーのボタン
- スレッドの行（クリックでスレッドを開く範囲）
- アカウントの見出しとリポジトリの見出しの、折りたたみの操作の範囲

塗りは、システムの文字色を薄く重ねた角丸の塗りにし、独自の色を使ってはならない（MUST NOT）。これは「ポップオーバーの文字の読みやすさ」が許すボタンの囲みの塗りであり、文字の色を変えてはならない（MUST NOT。すべて既読とリポジトリの Done の確認の文はアクセントカラーのまま）。マウスを外したら塗りを消さなければならない（SHALL）。押せないとき（再読み込み中の再読み込みのボタン、押せないすべて既読のボタン）と、折りたたみの操作を出さない見出しには、塗りを出してはならない（MUST NOT）。塗りを出しても、行と見出しの高さ、アイコンと文字の位置、件名の折り返しは変えてはならない（MUST NOT）。

スレッドの行では、行の塗りはマウスを載せた行の全体に出し、「既読にする」と「Done にする」のボタンを出している間も、ボタンの下を含めて行の全体に出し続けなければならない（SHALL）。ボタンにマウスを載せたときは、行の塗りの上にボタンの塗りを重ねて出さなければならない（SHALL）。リポジトリの見出しの折りたたみの操作の範囲は、見出しの行の幅いっぱいにしなければならない（SHALL）。リポジトリの見出しでは、「既読にする」と「Done にする」のボタンを出している間も、ボタンの下を含めて見出しの行の幅いっぱいに塗りを出し続け、ボタンにマウスを載せたときは見出しの塗りの上にボタンの塗りを重ねて出さなければならない（SHALL。スレッドの行と同じ）。アカウントの見出しの折りたたみの操作の範囲は、見出しの行のうち、Web の通知一覧とすべて既読のボタンの手前までの幅いっぱいにし（SHALL）、それらのボタンと重ねてはならない（MUST NOT）。

システム標準の押しボタン（Quit、Open Settings…、Open cli.github.com など）は、macOS の標準の見た目のままにし、独自の塗りを付けてはならない（MUST NOT）。

#### Scenario: スレッドの行にマウスを載せる

- **GIVEN** `github.com/alice` の一覧にスレッド `123` がある
- **WHEN** ユーザーが `123` の行にマウスを載せる
- **THEN** `123` の行の全体に薄い塗りが出て、右端に「既読にする」と「Done にする」のボタンが出る
- **AND** 件名の折り返しと行の高さは、マウスを載せる前と変わらない
- **AND** マウスを行から外すと、塗りとボタンは消える

#### Scenario: 行の操作のボタンにマウスを載せる

- **GIVEN** `123` の行にマウスを載せている
- **WHEN** ユーザーがマウスを「Done にする」のボタンの上へ動かす
- **THEN** 行の塗りは出たままで、「Done にする」のアイコンの後ろに角丸の塗りが重なって出る
- **AND** 「既読にする」のアイコンの後ろには塗りが出ない

#### Scenario: 見出しのアイコンのボタンにマウスを載せる

- **GIVEN** `github.com/alice` の一覧に 3 件ある
- **WHEN** ユーザーが `alice` の見出しのすべて既読のボタンにマウスを載せ、続けて Web の通知一覧のボタンにマウスを載せる
- **THEN** マウスを載せているボタンのアイコンの後ろにだけ、角丸の薄い塗りが出る

#### Scenario: すべて既読の確認の表示

- **GIVEN** ユーザーが `alice` の「すべて既読」を 1 回押し、`Mark 3 as read?` の表示になっている
- **WHEN** ユーザーがそのボタンにマウスを載せる
- **THEN** 確認の文の後ろに角丸の薄い塗りが出て、文はアクセントカラーのまま

#### Scenario: 押せないボタン

- **GIVEN** `github.com/alice` の取得ができていて、未読が 0 件
- **WHEN** ユーザーが `alice` の見出しのすべて既読のボタンにマウスを載せる
- **THEN** 塗りは出ない

#### Scenario: リポジトリの見出しにマウスを載せる

- **GIVEN** `github.com/alice` に `octo/app` の通知が 2 件ある
- **WHEN** ユーザーが `octo/app` の見出しの、リポジトリ名より右の空いたところにマウスを載せる
- **THEN** 見出しの行の幅いっぱいに薄い塗りが出る
- **AND** そこを押すと `octo/app` が折りたたまれる

#### Scenario: アカウントの見出しにマウスを載せる

- **GIVEN** `github.com/alice` の一覧に 3 件ある
- **WHEN** ユーザーが `alice` の見出しの、ホスト名と Web の通知一覧のボタンの間の空いたところにマウスを載せる
- **THEN** 山形から Web の通知一覧のボタンの手前までに薄い塗りが出て、すべて既読と Web の通知一覧のボタンには塗りが出ない
- **AND** そこを押すと `alice` の区画が折りたたまれ、すべて既読のボタンは確認の表示にならない

#### Scenario: 折りたたみの操作を出さない見出し

- **GIVEN** `ghe.example.com/dave` が「トークンを取れない」
- **WHEN** ユーザーが `dave` の見出しにマウスを載せる
- **THEN** 見出しに塗りは出ない

#### Scenario: 標準の押しボタン

- **GIVEN** ポップオーバーが開いている
- **WHEN** ユーザーが Quit ボタンにマウスを載せる
- **THEN** Quit ボタンは macOS の標準の押しボタンの見た目のままで、独自の塗りは出ない

#### Scenario: リポジトリの見出しの操作のボタンにマウスを載せる

- **GIVEN** `github.com/alice` に `octo/app` の通知が 2 件あり、`octo/app` の見出しにマウスを載せている
- **WHEN** ユーザーがマウスを見出しの「Done にする」のボタンの上へ動かす
- **THEN** 見出しの行の幅いっぱいの塗りは出たままで、「Done にする」のアイコンの後ろに角丸の塗りが重なって出る
- **AND** 見出しの高さとリポジトリ名の位置は、マウスを載せる前と変わらない
