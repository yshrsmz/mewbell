# 引き継ぎメモ（handover.local.md）

リポジトリのルートの `handover.local.md` は、セッションをまたいで作業を引き継ぐためのローカル専用のメモ。`.gitignore` の `*.local.md` で除外していて、コミットしない。作業を再開するときに読む。

## 書いてよいもの

- 今の状態のうち、調べてもわからないもの（手元で何を試している途中か、など）
- まだ決まっていないこと（ユーザーの判断待ち、方針が固まっていない点）
- まだ change に起こしていない ToDo（手で確かめる項目、次に検討したいことなど）

## 書かないもの

- 調べればわかること。PR やブランチの状態、マージ済みのコミット、リリースの有無などは `git` と `gh` で確かめる
- 終わったことの経緯や記録。終わった項目は消す。記録として残すなら PR 本文や `openspec/changes/` の tasks.md に書く
- 恒久的な約束やノウハウ。CLAUDE.md・`.claude/rules/`・`openspec/` に書く

書くことが無ければ、節を空のままにするか、ファイルを消してよい。
