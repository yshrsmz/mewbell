# update-architecture-doc

`docs/architecture.md` を、変更の漏れと記述の重複を起こさずに更新する。機械的に見つけられる漏れは `bash scripts/check-architecture.sh` が見つけるので、ここでは判断が要る部分を扱う。

## どの約束をどこに書くか

約束の本文は、次の表の 1 か所にだけ書く。ほかの文書からは、原則の ID（`A3` など）か文書のパスで引くだけにする。

| 約束 | 本文を書く文書 |
| --- | --- |
| 振る舞い（ユーザー・API から見えるもの） | `openspec/specs/` |
| セキュリティの約束 | `.claude/rules/security.md` |
| コードの構造の約束（層・依存の向き・状態の持ち方・境界・部品の足し方・テストの方針） | `docs/architecture.md` |
| 開発の進め方、ビルドとテストの方法、ツールの癖 | `CLAUDE.md`、`.claude/rules/` |
| artifact ごとの書き方の規則 | `openspec/config.yaml` |
| 正規表現で守れる約束 | `.swiftlint.yml` の `custom_rules`（`message` に原則の ID を書き、原則の「根拠」にも lint の規則の名前を書く） |

書く前に、同じ約束がすでにどこかにないかを `grep` で探す。言い換えた重複は検査では見つからないので、ここで止める。見つけたら、表で受け持つ文書に本文を寄せ、もう一方は参照に置き換える。

## 原則の書式

```
### A<番号>. <原則を 1 文で>

- **原則**: 今の形。型名やパスはバッククォートで書く（検査がコードに実在するかを確かめる）
- **理由**: なぜその形か
- **採らなかった案**:
  - <案>: <採らない理由>
- **適用外**: 例外の場所と理由（無ければ「なし」）
- **根拠**: <change 名> D<番号>、…（lint で守るものは規則の名前も）
```

- 書くのは今の形だけにする。「〜だったが、〜に変えた」のような経緯は書かない。経緯は根拠の change の design.md にある
- ID は次の番号を振り、再利用しない

## 手順

### 原則を足す

1. 別の機能を足すときにも同じ問いが出るかを確かめる。その change の中だけの判断なら、design.md に書けば足りる
2. 既存の原則に書き足せないかを先に探す。同じ問い（置き場所、境界、状態の持ち方など）を扱う原則があれば、そちらに書き足す
3. 足すなら、次の番号で 5 項目を埋める。「根拠」には、決めた change の名前と Decision の番号を書く
4. 今のコードが原則に合わなければ、「既知の逸脱」に行を足す（直す change の名前は仮でよい）
5. 正規表現で守れるなら、`.swiftlint.yml` に規則を足し、`message` に ID を書く

### 原則を改める

改めるのは、そのための change の中で行う（`openspec/config.yaml` の規則）。

1. 本文を今の形に書き換える。前の形を「採らなかった案」に移すのは、また提案されそうなときだけにし、採らない理由を書く
2. `grep -rnw 'A<番号>' CLAUDE.md .claude openspec .swiftlint.yml docs` で、その ID を引いている箇所をすべて開き、新しい形と食い違わないかを確かめる。archive の design.md は当時の記録なので直さない
3. lint の規則の正規表現と `message` を新しい形にそろえる
4. 今のコードが新しい形に合わなくなるなら、「既知の逸脱」に足す。合うようになった行は消す

### 原則を廃止する

1. 見出しを `### A<番号>. 廃止（<change 名>）` にし、本文を `- **廃止の理由**: …` の 1 行にする
2. その ID を引いている lint の規則と、archive でない文書の参照を外すか、引き継ぐ原則に引き直す
3. 「既知の逸脱」のその原則の行を消す

### 既知の逸脱を直した・見つけた

- 直したら、その行を消す。原則の「適用外」に同じものが書かれていれば、それも消す
- 見つけたら、原則・場所（ファイルと型）・直す change の名前で行を足す。直す change を起こすまでの ToDo は `handover.local.md` に書いてよい

## 最後に

```bash
bash scripts/check-architecture.sh
```

を通す。
